# Виано Мебель

От идеи до установки.

Локальное приложение для прайсов .xls и .xlsx. Интерфейс работает в браузере, база SQLite и фотографии остаются на вашем компьютере.

## Запуск
Дважды нажмите **Start.cmd**. Каталог откроется по адресу http://127.0.0.1:8765/.
Start.cmd автоматически ищет рабочий Python 3.12 или новее (проверяет версию и нужные системные модули). Если подходящего Python нет, скачивает официальный установщик Python 3.13.16 с python.org, сверяет SHA-256 и устанавливает его для текущего пользователя, затем открывает каталог. Первичная установка требует интернет; следующие запуски и работа с базой возможны без интернета.

Python устанавливается в %LOCALAPPDATA%\VianoMebel\Python313. Системный PATH, файловые ассоциации и другие установки Python не меняются. На этом компьютере уже найден подходящий Python Codex. Библиотеки чтения Excel включены в папку vendor.

Для передачи приложения дважды нажмите **Create-Archive.cmd**. Готовый ZIP появится в папке **exports**. В него включаются приложение, снимок базы SQLite, привязанные фотографии, сохранённые прайсы и прежние резервные копии. Каталог можно оставить открытым: снимок SQLite учитывает журнал WAL, а занятые логи .runtime, временные проверки .qa/.analysis, кэш Python и прежние архивы exports исключаются. После обычной распаковки ZIP на другом компьютере откройте папку IBD и дважды нажмите Start.cmd. Не запускайте из окна просмотра ZIP без распаковки.

При ошибке скачивания или установки окно покажет причину; повторите запуск после её устранения. Журналы установки находятся в %LOCALAPPDATA%\VianoMebel\Installers, журналы запуска — в .runtime/logs. Проверка без установки и открытия: powershell -NoProfile -ExecutionPolicy Bypass -File Start.ps1 -CheckOnly.

Для запуска вручную: python -X utf8 server.py
Для остановки: powershell -NoProfile -File Stop.ps1

При ручной архивации через WinRAR сначала остановите сервер через Stop.ps1 (закрытие вкладки браузера не останавливает сервер). Для обычной передачи удобнее Create-Archive.cmd: остановка не нужна.

## Работа
Нажмите «Загрузить прайс», выберите Excel-файлы, проверьте фабрику, листы и колонку исходной цены. В режиме «Добавить только новые» существующие позиции сохраняются. В режиме обновления пересчитывается цена из нового прайса. Перед импортом видны новые позиции, дубли и проблемы.
Цена продажи = цена из прайса × 1,20 + 1000 ₽. Настройки позволяют менять наценку и округление.
При импорте прайса встроенные фотографии Excel добавляются автоматически. В предпросмотре видны миниатюры и количество новых фотографий. Общая фотография объединённого блока товара привязывается ко всем его размерам. Логотипы до заголовка и значки вне колонки фото пропускаются. При неоднозначной привязке показывается предупреждение. Внешние ссылки на картинки не скачиваются; фотографии внутри ячеек нового формата richData требуют преобразования в рисунки над ячейками. Стандартные рисунки XLSX и рисунки OfficeArt в XLS поддерживаются; JPEG, PNG и WebP работают без дополнительных библиотек. Неподдерживаемая или повреждённая фотография не мешает загрузить товар.

Если в прайсе фото нет, добавьте его через карточку товара. Ручные фотографии и выбранное основное фото сохраняются. В режиме добавления новых повторный прайс также может заполнить фотографии существующих позиций, сохраняя их цены. Повторы снимков не добавляются, а удалённое пользователем импортированное фото не возвращается при очередной загрузке того же изображения. Ручные исправления сохраняются при обновлении.
Для папки используйте отдельную папку только с мебельными прайсами. Автообновление проверяет изменения каждые 30 секунд, пока программа запущена. Неоднозначные строки требуют проверки. Служебные файлы Excel (~$) игнорируются.
В «Резервной копии» можно сохранить ZIP всей базы с фотографиями и восстановить его. Перед восстановлением программа автоматически сохраняет прежнюю базу в data/backups.

## Где данные
data/catalog.sqlite3 — личный каталог; data/photos — ваши изображения; data/incoming — снимки загружаемых прайсов.
Для переноса между компьютерами используйте резервную копию через интерфейс. Не копируйте открытую SQLite-базу через облачную синхронизацию.
Не удаляйте папку data: она содержит ваши товары и фотографии.

## Обработка прайсов
Если в прайсе отдельное поле цвета пустое, конкретный оттенок автоматически извлекается из наименования при отображении карточек, таблицы и предпросмотра. Полное исходное название сохраняется; явный цвет и ручная правка имеют приоритет. Названия коллекций и общие палитры не назначаются всем товарам как цвет.

Для типовых приложенных прайсов есть автоматическое распознавание. Переносы и дефисы внутри заголовков вроде «НАИМЕНО-ВАНИЕ» учитываются; буквенные обозначения без заголовков показываются как «Столбец D». Объединённое название с разными размерами и ценами сохраняется отдельными позициями. Новый формат может требовать выбора столбцов; профиль сохраняется для следующих загрузок того же семейства файлов.
Дубли определяются по фабрике, коллекции, артикулу и варианту; при отсутствии артикула — по названию, цвету и размерам. Сходные названия не объединяются автоматически.
Размеры сохраняются в исходной записи, отсутствующие не выдумываются. Проблемные цены и конфликтующие дубли не включаются в импорт до проверки исходных данных.

## Проверка
python -X utf8 -m unittest discover -s tests -v
Проверка автозапуска в Windows PowerShell 5.1: powershell -NoProfile -ExecutionPolicy Bypass -File tests/test_launcher.ps1

Тесты используют отдельные временные базы и не меняют ваш каталог. Проверки отсутствующего Python и установки моделируются без изменения установленных программ; перенос и запуск новой копии проверяются на реальном временном сервере.

Текущая версия локальная. Кабинеты через интернет не включены; структура приложения позволяет добавить отдельное серверное хранение позже.


Поиск по размерам: кнопка «Размеры» рядом с фильтрами. Введите числа как в прайсе либо задайте диапазоны в мм; для неподписанных записей подтвердите «Ш × В × Г, миллиметры» одной кнопкой либо выберите свой порядок и исходные единицы. Диапазон ширины до 1901 включает также 1900 и 1901. Интерфейс показывает размеры, которые не удалось распознать.

Обновление программы: кнопка «Обновить программу» или Update.cmd. Стандартный источник — GitHub Releases проекта Michail-S1/viano-mebel. Create-Update.cmd создаёт маленький пакет без личной базы и фото. Подробности — UPDATES.md. Варианты бесплатной автономной работы описаны в AUTONOMY.md.
