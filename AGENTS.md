# Проект «Каталог мебели»

Перед изменениями прочитай PROJECT_PROMPT.md. Новые указания пользователя имеют приоритет.

Архитектура: локальный Python-сервер server.py, импорт backend/importer.py, интерфейс static/. База и фотографии в data/. Не изменять исходные прайсы, импортировать встроенные фото из Excel при однозначной привязке к товару, сохранять ручные фото и не создавать повторы, сохранять ID и ручные изменения при обновлении.

Проверка: python -m unittest discover -s tests -v. Для API/UI проверок использовать отдельную временную data-dir, чтобы не менять личные данные. Все ассеты локальные; публикация в интернет пока не запрошена.
