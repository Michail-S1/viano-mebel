# Обновление программы Виано Мебель

После однократного подключения источника новые версии устанавливаются из интерфейса: «Обновить программу» → «Проверить» → «Установить обновление». Также можно запускать Update.cmd. Интернет нужен только для получения версии; каталог продолжает работать без интернета.

Источник пока не опубликован и не настроен. Поддерживаются HTTPS-ссылка на latest.json и полный путь к такому файлу, например в общей папке. Прайсы, база и фото в источник обновлений не отправляются.

## Для пользователя

1. Открыть «Обновить программу» в боковой панели или в настройках.
2. Один раз указать адрес latest.json, предоставленный владельцем проекта.
3. Нажать «Проверить». Программа сохранит адрес.
4. Если есть новая версия, нажать «Установить обновление».
5. Дождаться перезапуска. Страница автоматически перечитает новую версию.

Файлы data/, update-source.json и личные настройки каталога не заменяются. Перед изменением кода сохраняется предыдущий код в .runtime/before-update-*. Проверяется SHA-256, структура пакета и синтаксис Python. Если новый сервер не запускается, возвращается прежний код. При отсутствии связи или некорректном пакете установленная программа продолжает работать.

Обновление поддерживается только в основном каталоге приложения. Тестовые --data-dir не могут менять файлы программы.

## Для владельца проекта или разработчика

1. Изменить VERSION в server.py (например, 1.2.0 → 1.2.1).
2. Запустить проверки: python -m unittest discover -s tests -v.
3. Запустить Create-Update.cmd либо Create-Update.ps1 -NoPause.
4. В exports/update появятся latest.json и Viano-update-<версия>.zip. В них только программа; данных пользователя нет.
5. Разместить оба файла в постоянном источнике. При повторной сборке той же версии выбрать новую выходную папку.
6. Пользователи нажимают «Проверить» и «Установить обновление».

Пример постоянного адреса на GitHub:
https://github.com/OWNER/REPOSITORY/releases/latest/download/latest.json

GitHub Releases позволяет прикрепить оба файла к версии. Для текущего простого обновляющего клиента нужны доступные по HTTPS файлы без входа в аккаунт; приватный репозиторий с закрытыми release assets требует отдельного решения для авторизации. Публичным можно сделать только код, а каталог и фотографии остаются локальными. GitHub Free: https://github.com/pricing
Ссылка на последний файл релиза: https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases

Формат latest.json:
{
  "app": "viano-furniture-update",
  "version": "1.2.0",
  "url": "Viano-update-1.2.0.zip",
  "sha256": "контрольная сумма из Create-Update.cmd",
  "notes": "Описание изменения"
}

Переход с версии до 1.2.0 на другом компьютере: остановить Python-сервер этой папки (Stop.ps1), распаковать маленький пакет обновления в существующую папку IBD с заменой файлов программы, запустить Start.cmd. Папка data в пакете отсутствует. После этого для следующих версий достаточно кнопки обновления.

Полный Create-Archive.cmd остаётся для первого переноса приложения вместе с личной базой, а не для регулярного обновления.
