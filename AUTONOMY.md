# Автономность Виано Мебель

Проверено 12 октября 2026 года. Цены и ограничения внешних сервисов могут меняться.

Текущее приложение самостоятельно читает Excel, считает цены, хранит базу и фото. Для повседневной работы не нужны Codex, платная подписка, внешний сервер или интернет. Start.cmd использует установленный Python; интернет требуется при его первой установке и для получения обновлений. Исправления и новые функции создаёт разработчик; программа сама проверяет и устанавливает подготовленные версии.

## Рекомендуемый следующий шаг: локальное приложение и бесплатный источник обновлений

Оставить личные данные на компьютерах пользователей. Разместить только код и небольшие пакеты обновления на GitHub Releases. Это сохраняет текущий импорт .xls/.xlsx и не требует переносить базу в облако. Пользователь один раз настраивает источник, затем обновляется кнопкой. Чтобы проект мог поддерживать другой разработчик, правила, проверки и сборка версии описаны в PROJECT_PROMPT.md и UPDATES.md.

GitHub Free предусматривает публичные и приватные репозитории; для клиента без входа в аккаунт подходят публичные файлы релиза:
https://github.com/pricing
https://docs.github.com/en/repositories/releasing-projects-on-github/linking-to-releases

## Вариант 1: готовая программа Windows без установки Python

Можно собрать запускной .exe с встроенным Python через PyInstaller. Тогда первая установка сможет работать без интернета. Потребуется отдельная сборка и проверка, адаптация путей постоянных данных и обновляющего процесса под .exe. Эта сборка пока не выполнена. PyInstaller допускает упаковку коммерческих приложений:
https://pyinstaller.org/en/stable/operating-mode.html
https://pyinstaller.org/en/stable/license.html

## Вариант 2: доступ через интернет к своему включённому компьютеру

Сервер остаётся на вашем компьютере; удалённые устройства подключаются через защищённый канал. Это сохраняет Python-импорт. Компьютер должен быть включён, интернет должен работать. Потребуются вход в аккаунт и разделение личных баз. Сейчас доступ приложения ограничен 127.0.0.1, поэтому просто передать ссылку другому устройству нельзя.

Cloudflare Tunnel вместе с Access можно использовать для защищённого входа: бесплатный план Zero Trust рассчитан на 50 пользователей. Для постоянного именованного туннеля обычно нужен домен, который может быть платным:
https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/
https://www.cloudflare.com/plans/zero-trust-services/

Tailscale Personal не предлагается здесь как бесплатное решение для магазина: его бесплатный тариф предназначен для некоммерческого личного использования:
https://tailscale.com/pricing

## Вариант 3: полностью облачная версия

Кабинет каждого пользователя, своя база и фото, работа из любого браузера; ваш компьютер можно выключать. Возможный бесплатный старт — Cloudflare Workers + D1 + R2.

На бесплатных тарифах: Workers 100 000 запросов в сутки и 10 мс CPU на запрос; D1 5 ГБ всего и 500 МБ на одну базу; R2 Standard 10 ГБ хранения в месяц плюс ограничения операций. Выход за квоты может привести к отказам или оплате. Это не обещание бесплатной работы при любом количестве пользователей и фотографий.

Потребуются отдельная веб-версия серверной части, авторизация, изоляция данных пользователей, адаптация импорта Excel (существующий Python-сервер нельзя просто загрузить в Workers) и резервное копирование. Тяжёлый разбор прайсов нельзя планировать как обычный запрос с лимитом 10 мс: понадобится обработка на устройстве пользователя либо другой исполнитель.

https://developers.cloudflare.com/workers/platform/limits/
https://developers.cloudflare.com/d1/platform/pricing/
https://developers.cloudflare.com/d1/platform/limits/
https://developers.cloudflare.com/r2/pricing/

Для текущего режима «основной компьютер, у каждого свой прайс» рекомендуется сначала локальная работа с обновлениями через GitHub, затем при необходимости отдельная облачная версия.
